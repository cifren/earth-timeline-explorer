# Frise Chrono — web

React web application of Frise Chrono: a flat world map to pick a zone, a timeline to
pick a decade, and a panel showing a random photograph of that zone and period. It holds
no business rule: everything it displays comes from the back's API.

## Start

From the repository root (see the [root README](../README.md) for the first setup):

```bash
./compose up web        # starts the web, the back and Redis
./compose logs web      # follows its logs
```

The application runs on http://localhost:5173 with hot reload. It calls the API at the
address given by `VITE_API_URL` (`http://localhost:8080` in development).

## Commands

Run with `./compose make web <target>`:

| Target    | Action                                                     |
|-----------|------------------------------------------------------------|
| `help`    | List the commands                                          |
| `install` | Install the npm dependencies                               |
| `dev`     | Run the development server (default command of the container) |
| `build`   | Build the static bundle into `dist/`                       |
| `lint`    | ESLint and Prettier check, including architecture boundaries |
| `format`  | Format the code with Prettier                              |
| `api`     | Regenerate the API client from `../back/api/openapi.yaml`  |

## Stack

React and TypeScript (strict), built with Vite; TanStack Query for API data, Zustand for
user selections; OpenLayers for the map; Tailwind CSS and shadcn/ui for components;
API client generated by Orval from the back's contract.

## Code layout

Simplified DDD ([ADR common 0004](../docs/adr-common/0004-bounded-contexts-and-clean-layers.md),
[ADR web core 0001](docs/adr-core/0001-react-layout-for-contexts-and-layers.md)):

```
src/
├── app/                   composition root: routes, providers, page shells
├── bounded-contexts/
│   ├── geography/         map
│   ├── chronology/        timeline
│   └── imagery/           photo panel, full-screen viewer
├── core/exploration/      selected zone and decade
└── shared/
    ├── api-client/        generated from the contract (never edited)
    └── ui/                shadcn/ui components
```

**Changing the API usage**: after a contract change in the back, run
`./compose make web api` and fix what the TypeScript compiler reports in the
`infrastructure` mappers.

## Production image

```bash
docker build --target prod --build-arg VITE_API_URL=https://api.example.org -t frise-chrono-web web/
```

Static files served by Caddy, with long-lived caching on hashed assets
([ADR web devops 0001](docs/adr-devops/0001-dev-server-and-static-production-build.md)).
