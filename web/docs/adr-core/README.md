# ADR — Web core (React application baseline)

These Architecture Decision Records define the **reusable baseline of a React
application**: folder layout, components, state, generated API client, typing, lint,
scaffolding. They apply the common conventions of
[`../../../docs/adr-common/`](../../../docs/adr-common/) to React and TypeScript.

Decisions specific to this web application live in [`../adr-functional/`](../adr-functional/);
its build and run in [`../adr-devops/`](../adr-devops/). Read them in order.
