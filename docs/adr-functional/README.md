# ADR — Functional (whole system)

These Architecture Decision Records capture decisions driven by the **Frise Chrono
business needs** that apply to the whole system: how the repository serves the product,
where the business rules live, how the applications share one business vocabulary and
one API contract, how source images are used.

Related folders:

- [`../adr-common/`](../adr-common/) — conventions shared by every application;
- [`../adr-devops/`](../adr-devops/) — how the whole system is built and run;
- [`../../back/docs/`](../../back/docs/) — Go service decisions;
- [`../../web/docs/`](../../web/docs/) — React web application decisions.

Format: [Michael Nygard's ADR template](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions.html)
— Context / Decision / Consequences, kept short. Read them in order.
