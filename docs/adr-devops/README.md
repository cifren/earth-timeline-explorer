# ADR — DevOps (whole system)

These Architecture Decision Records capture decisions about **how the system is built,
run and operated** as a whole: containerisation, command entrypoints, local environment.
Build and run decisions specific to one application live in its own `docs/adr-devops/`.

Format: the same [Nygard template](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions.html)
as the other ADRs. Add a decision as `NNNN-kebab-title.md`; read them in order.
