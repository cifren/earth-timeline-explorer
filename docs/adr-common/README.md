# ADR — Common (every application)

These Architecture Decision Records define the **conventions shared by every application**
of the repository (back, web, later mobile), whatever its language: how decisions are
written, how code is linted and formatted, how code is structured and written.

Each application's `docs/adr-core/` turns these conventions into concrete tools and folder
layouts for its stack; it never contradicts them.

Format: [Michael Nygard's ADR template](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions.html)
— Context / Decision / Consequences, kept short. Read them in order.
